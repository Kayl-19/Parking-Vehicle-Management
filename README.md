# Parking Vehicle Management System

Integrated Java Swing Application for IT20 (Data Structures and Algorithms) & IT21 (Object-Oriented Programming).

## Project Overview
A Java desktop application for managing parked vehicles, tracking parking spots, and conducting linear search lookups across vehicle records without standard library collections (`java.util.*`).

## Features
* **IT20 Data Structure:** Manually Coded Doubly Linked List (`CustomDoublyLinkedList`) built from scratch.
* **IT20 Search Algorithm:** Manual Linear Search scanning linked nodes by Plate Number, Spot ID, Owner Name, or Type.
* **IT21 OOP Design:** Abstract base class `Vehicle` with `Car`, `Motorcycle`, and `CustomVehicle` subclasses using inheritance and encapsulation.
* **GUI & Interactivity:** Java Swing interface featuring dynamic vehicle type insertion, table displays, and real-time validation checks.

## Team Roles
* **Partner A:** IT20 Custom Doubly Linked List, insertion/deletion pointer logic, array conversion, and linear search implementation.
* **Partner B:** IT21 Abstract domain model hierarchy, Swing GUI layout, ComboBox selection listeners, input validation, and documentation.
